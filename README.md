## NowDo v2.0 · Mac 原生版

面向使用苹果日历、希望记下实际投入时间的人。一次只计一件事，点紫点暂停或继续，回来打开复盘看时间花在哪里。

- **开始一件事**：日历事项拖入入口、日历列表或临时事项。
- **随手暂停和继续**：悬浮点留在桌面，切换事项自动暂停上一件。
- **留下下次规划的依据**：实际用时、分段记录、备注修正与导出。
- **先看一遍**：设置中有约 22 秒的独立示例演示，不写入正式记录。

免费开源，MIT 许可。没有账号、订阅或 AI API 要求。**当前是开源预览版：核心与输入边界已测试，修复后的真实 Calendar 拖入、原生右键菜单和跨机器安装仍待完整验收。**

## 原有网页版


一万年太久，只争朝夕。designed by even.

nowdo 是按任务保留进度的轻量行动工具：想到一件事就说或写下来，停下来时记下做到哪了，回来沿着同一条任务继续。适合需要在写作、开发、沟通等多件事之间切换的人。

- 输入一句话，按日期和事项生成主任务与子任务。
- 明确说出时间，例如“明天下午3点检查文案”或“10分钟后看看结果”，可设置提醒。
- 多件主任务可以同时处于“正在做”，各自记录用时。
- 暂停必须写进度；“做完了”完成当前子任务，主任务保留，之后还能继续。
- 支持浏览器语音输入，也可以直接打字；不需要 nowdo 账号。

## 打开与使用

网页：https://wangyiwen11.github.io/nowdo-web/

使用教程：https://wangyiwen11.github.io/nowdo-web/#guide

试试输入：

- `今天整理演示素材；明天下午3点检查发布文案`：分别放到今天和明天。
- `提醒我中午11点50回家，拿充电器和鼠标，顺便取个快递`：一个主任务，三个子任务。
- `现在做整理素材`：创建后立即开始。

只写日期、没有具体时间或时段时，只安排日期，不擅自设置提醒。自动拆分是本地规则解析，支持的表达有限；提交前请检查预览，复杂内容可以分句输入。

## 提醒与记录

- 页内提醒需要页面运行。系统通知还取决于浏览器权限和设备支持。
- 关闭页面、后台运行或锁屏时，不保证准时提醒。添加到主屏幕或离线缓存不会改变这一限制。
- 任务记录保存在当前设备、当前浏览器的 localStorage 中；没有账号、云同步或自动备份。
- 清理网站数据、使用无痕窗口、换浏览器或换设备，都可能无法看到原来的记录。目前没有导入导出入口。
- 语音识别由浏览器提供，可能使用浏览器厂商的在线服务；不承诺语音离线处理。打字录入不需要语音服务。
- 支持打开任务中识别到的网页链接。网页版不能直接打开本机应用或文件。
- 本项目不提供打卡、社交或团队协作功能。
