# NowDo · 计时点

**给苹果日历用的 Mac 悬浮秒表。**

日历里已经安排了要做的事，真正开始时，把那条日程拖到桌面的紫色小点，NowDo 就开始记录用时。被打断，点一下暂停；回来，再点一下继续。做完看看实际花了多久，给下一次安排时间留个依据。

免费开源 · 无需登录 · 记录保存在这台 Mac

[下载 Mac 版](https://github.com/wangyiwen11/nowdo-web/releases/tag/v2.0.0) · [第一次怎么用](macos/docs/GETTING-STARTED.md)

*当前为 v2.0 预览版。下载包适用于 Apple Silicon（M 系列芯片），最低系统目标为 macOS 14。尚未经过苹果公证，首次打开可能被系统拦截，见下方安装说明。*

## 什么时候会用到它

你计划用半小时写文章，中途回复消息，回来又写了一会儿。到晚上，只记得忙了很久，却不清楚文章本身用了多少时间；下次排日历，还是只能凭感觉。

用 NowDo 时，离开这件事就暂停，回来继续。它会把同一件事的几段时间加起来，留下可以回看的记录。你不用再建一遍任务，也不用自己计算每段用了多久。

适合已经用苹果日历安排事情、经常在工作之间切换、想知道自己实际投入了多少时间的 Mac 用户。

## 日常只用三个动作

1. **把日程拖到紫点，开始记录。** 看到事项名称和递增的秒表，就可以开始做事。
2. **点紫点暂停，再点继续。** 去处理别的事时暂停，回来接着累计。开始另一条日程时，上一件会自动暂停，一次只记一件事。
3. **做完暂停，打开“复盘”。** 点小点右侧的箭头展开窗口，查看每件事的实际用时、分段和原计划；需要时留一句备注。

![收起后的紫色计时点：点击继续，右侧箭头展开窗口](macos/docs/previews/dot.png)

*小点示例：当前已暂停，25:00 是示例累计时间。点击播放图标继续计时。*

## 复盘能帮你看清什么

假设“写文章”计划 30 分钟，你先做了 18 分钟，暂停处理消息，回来又做了 24 分钟。

| 复盘内容 | 这个例子里会看到什么 |
| --- | --- |
| 实际投入 | 合计 42 分钟，暂停期间不计入 |
| 与计划比较 | 原计划 30 分钟，实际多用了 12 分钟 |
| 分段记录 | 两段工作的开始、暂停时间 |
| 自己的备注 | 可以写“查资料花了较久，下次先限定资料范围” |

*以上是说明用的例子，不是实际用户数据。原因由你结合记录判断和填写，NowDo 不会自动推断你为什么超时。*

忘记暂停时，可以把已结束记录的结束时间改早；想做进一步整理，可以导出当天的表格或备份全部记录。

## 下载后怎么开始

1. 打开[下载页](https://github.com/wangyiwen11/nowdo-web/releases/tag/v2.0.0)，选择 **NowDo-v2.0.0-macOS-arm64.zip**。不要选 Source code，那是程序源码。
2. 解压，把 **NowDo 计时点.app** 放进“应用程序”，再打开。
3. 在 **设置 → 看一遍 22 秒使用演示** 里先看一次操作。演示使用独立示例，不写入你的正式记录。
4. 看完后关闭演示，从菜单栏 **NowDo → 显示悬浮小点** 找到紫点，再把一条日程拖过去，开始自己的第一段记录。

当前安装包没有 Apple Developer ID 签名或公证。如果系统拦截首次打开，确认下载来源后，可使用“系统设置 → 隐私与安全性”提供的打开选项。也可以从源码构建；无需关闭系统整体安全保护。

如果没有日程，或拖入没有成功提示，可以先用 **“加一件临时事项 → 开始”** 记录，再查[常见问题](macos/docs/FAQ.md)。

## 使用前知道这几件事

- **需要你开始和暂停。** 它不会自动判断你是否在工作，也不会监视屏幕。正常休眠或退出时会暂停。
- **一次记录一件事。** 可以保留多件事项的历史，但不会同时运行多个秒表。
- **记录保存在本机。** 应用不上传计时记录、不修改原日历，不提供跨设备同步。可在设置中备份，避免清理数据或更换设备后丢失。
- **目前仍是预览版。** 2026-10-22，原反馈用户已确认在其 Mac 上，真实苹果日历日程拖到紫点后正常开始计时。其他设备与账户、日历右键入口，以及完整记录流程的真实使用验收仍在完善；详细范围见[验证记录](macos/docs/QA.md)。
