# 第一次用 NowDo

NowDo 记的是“这件事实际用了多久”。你开始它，点一下暂停，再点一下继续，最后在“复盘”里看记录。

**当前是 v2.0 开源预览版。** 最低目标 macOS 14；现有本机构建为 Apple Silicon。公开公证安装包尚未完成发行验证。已有应用就从下一步开始；只有源码时，请先请熟悉 Mac 开发的人按 [构建说明](../README.md#从源码运行)生成应用。

## 1. 先用示例看懂小点

打开 **NowDo 计时点**，点击 **“先用示例试试”**。

1. 在示例列表里点一件事。卡片出现事项名称，秒表开始增加。
2. 点窗口右上角的收起按钮。窗口变成一个紫色小点，计时继续。
3. 点紫点。数字停止，表示暂停；再点一次，继续累计。
4. 点小点右侧的箭头，打开 **“复盘”**，查看这件事的实际用时。

示例界面会标明 **“示例体验 · 不保存到正式记录”**。示例里预置了一段历史记录，用来展示复盘长什么样；那不是你的工作记录。完成后点 **“结束体验”**。

也可在 **设置 → 看一遍 22 秒使用演示** 自动观看完整流程。开发者可用 `--guided-demo` 启动同一演示，依次显示开始、收起、暂停、继续和复盘。它只使用内存中的示例，不读取日历；**它没有代替苹果日历的真实拖拽验证。**

## 2. 试着接收一条日程

先用一条不含个人信息的测试事项，例如“读文章”，确认你的环境可以接收。

1. 在苹果日历中找到这条**日历事项**，不要一次选多条；提醒事项暂不支持。
2. 将它拖到紫点中央，或展开窗口顶部的拖入区域。
3. 等待“正在记录”提示，确认显示了正确的事项名称，数字开始增加。

只有第 3 步出现，才说明计时真正开始。看到光标变化或目标高亮，本身不代表接收成功。

**当前拖入兼容性仍在回归验证。** 旧版在部分 Calendar 环境中没有接收到异步交付的日程文件，表现就是“拖过去没反应”。新版加入了接收处理，但尚未完成所有真实场景验证。没有成功提示时，停止重复拖动，先使用下面的替代入口。

## 3. 拖不进来，也可以开始记

最快的替代入口是 **“加一件临时事项”**：填一个简短名称，计划分钟数可以不填，点 **“开始”**。它只在 NowDo 留下计时记录，不会替你新建日历事项。

如果希望使用现有日程，点 **“连接苹果日历”**，在系统弹窗中允许访问，然后从列表点选事项。系统会请求完整日历权限，应用目前只读取日程。在 **“设置”** 中可选择哪些日历显示出来。真实账户的同步表现仍需按本机环境确认。

以后接收另一件事或点击另一件事项，原来的计时会自动暂停。一次只记录一件事，无需逐个停止旧秒表。

## 4. 做完后看什么

在 **“复盘”** 里先看这件事用了多久，再看每一段从什么时候开始、什么时候暂停。有计划时长的事项，会同时显示原计划和累计用时。

全天事项不把 24 小时当作计划。跨天计时会分别进入对应日期的统计；同一事项的计划对比使用累计用时。

你可以在 **“修正 / 备注”** 写一句：

> 查资料花了较久；下次先限定要回答的两个问题。

如果忘记暂停，把已结束记录的结束时间改早再保存。它目前只支持缩短这段时间，不支持把未记录的整段工作凭空补进来。

## 5. 保存好自己的记录

时间段会自动保存到本机，无需点击单独的保存按钮；备注或时间修正则要点击 **“保存修正”**。如果出现保存错误提示，请先处理提示，不要把界面仍在计时当作已经写入成功。

- 想备份：**设置 → 备份全部记录**。
- 想拿去做复盘表：**复盘 → 导出当天**。
- 找不到小点：点菜单栏的 **NowDo → 显示悬浮小点**，或 **展开事项**。
- 想退出：用 NowDo 的退出入口。正常退出会暂停正在计时的事项。

下一次打开时，已有事项会保留，但不会自动开始计时；请在真正开始做事时点一下继续。

出现其他情况，查看 [常见问题](FAQ.md)。
