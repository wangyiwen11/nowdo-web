# NowDo v2.0 · 计时点

**给苹果日历用的 Mac 悬浮秒表。记录一件事实际花了多久，让下次安排时间更有依据。**

如果你已经把事情排进日历，却总是不清楚真正做了多久，可以试试 NowDo。它在桌面上留一个紫色小点：把正在做的日程拖进去就开始计时，被打断时点一下暂停，回来再点一下继续。做完打开“复盘”，看看这件事的累计用时、每一段记录和原计划。

免费开源 · 无需登录 · 记录保存在这台 Mac

## 一个例子就能看懂

计划写文章 30 分钟，先写了 18 分钟，暂停去处理消息，回来继续写了 24 分钟。NowDo 会留下两段记录，累计 42 分钟；暂停期间不计入。你可以记一句“查资料花了较久”，下次排时间时就有参考。

这是说明用的例子。原因由你结合记录判断，应用不会自动分析你的工作内容。

## 怎么用

1. **拖入日程开始。** 把苹果日历中的一条事项拖到紫点，看到名称和递增秒表后开始做事。
2. **点紫点暂停或继续。** 开始另一件事时，上一件自动暂停，一次只记录一件事。
3. **做完暂停，打开复盘。** 查看实际用时和分段，写一句备注；忘记暂停时可缩短已结束的记录，也可以导出当天表格。

第一次打开，可在 **设置 → 看一遍 22 秒使用演示** 里先看一次。看完关闭演示，从菜单栏 **NowDo → 显示悬浮小点** 找到紫点，再拖入日程。没有日程时，也可以“加一件临时事项”开始。

## 下载与安装

在本页 Assets 中下载 **NowDo-v2.0.0-macOS-arm64.zip**，解压，把“NowDo 计时点.app”放进“应用程序”后打开。Source code 是供开发者修改的源码，不是安装包。

下载包适用于 Apple Silicon（M 系列芯片），最低系统目标为 macOS 14。目前是预览版，尚未经过 Apple Developer ID 签名和公证。首次打开可能被系统拦截；确认来源后，可使用系统设置提供的打开选项，或自行构建，无需关闭系统整体安全保护。

## 适用范围

- 适合用苹果日历安排事情、经常切换工作、希望记录实际投入的 Mac 用户。
- 需要你主动开始和暂停，不会自动判断你是否在工作；一次只记录一件事。
- 记录保存在本机，应用不上传计时记录、不修改原日历；暂无跨设备同步。
- 2026-10-22，原反馈用户已确认在其 Mac 上，真实苹果日历日程拖到紫点后正常开始计时。完整记录流程的后续实际验收、其他设备与账户及日历右键入口仍待验证。
