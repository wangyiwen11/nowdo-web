# NowDo v2.0 · 免费开源预览版

日历里排好的事，实际花了多久？用一个紫色小点记下来。

这一版加入 Mac 原生悬浮秒表：日历事项计时、点一下暂停或继续、自动切换、实际用时复盘、修正备注与 CSV/JSON 导出。一次只记录一件事。

修复了原先仅接收直接 ICS 的兼容缺口，加入苹果日历异步日程文件接收，提供接收中、超时与失败提示；新增 22 秒独立示例演示。

计时记录保存在本机，不需要账号、订阅或 AI API。源码采用 MIT 许可，原网页版继续保留，两个版本的记录独立。

## 如何开始

下载 Apple Silicon 压缩包，解压后把“NowDo 计时点.app”放到 Applications，再打开。在设置中先看一次使用演示。也可以从源码构建。

该包使用本机签名，尚未经过 Apple Developer ID 签名和公证，macOS 可能拦截首次打开；只有在确认来源和内容可信后，使用系统设置提供的打开选项，或选择自行构建。不要关闭系统整体安全保护。

## 验证范围

- 本机 13 项计时核心场景、15 项日程解析场景、20 项文件交付边界检查通过。
- 原生应用模型与直接 ICS 快速入口的合成流程检查通过。
- 已确认旧版本无法识别真实 Calendar 的文件承诺格式，代码已修复。
- **修复后真实 Calendar 拖拽、原生右键菜单以及跨机器安装尚未完整验收。** 因此以预览版开放，不承诺所有系统和日历账户均已可用。
- 自动演示只使用示例数据；它不代表已经测试真实 Calendar 拖拽。

遇到问题请按教程使用日历列表或临时事项入口，并以不含私人日程的示例反馈。
