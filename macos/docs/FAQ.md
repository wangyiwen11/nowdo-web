# 常见问题

## 日程拖到紫点没有反应怎么办？

这是已收到的真实问题。旧版只处理直接传来的日程数据或文件，而实测环境中的苹果日历先交付一个“稍后提供文件”的请求，旧版没有接住。v2.0 增加了这一处理方式。**2026-10-22，原反馈用户复试后确认：在其 Mac 上拖入日程已经正常开始计时。** 这项确认只覆盖该环境的开始步骤；其他设备、账户以及后续完整记录流程仍需验证。

先确认只拖一条日历事项，目标是紫点中央或窗口顶部入口，日历应用保持打开。成功必须同时看到正确事项名称、“正在记录”提示和递增的时间。

没有成功提示时，使用 **“加一件临时事项 → 开始”**，或 **“连接苹果日历 → 点选事项”**。不用持续反复拖拽，也不用开通录屏、辅助功能或剪贴板监控权限。

报告问题时只需说明系统版本、应用版本、拖入来源、是否有提示；可用自建的“测试事项”复现。请勿在公开问题区上传真实日历文件。

## 能在苹果日历里右键直接开始吗？

应用注册了系统服务 **“用 NowDo 开始计时”**。发送应用需要提供选中事项，服务才能收到数据。它是否出现在苹果日历事项的右键菜单，尚未验证；注册服务不代表已经改造了 Calendar 的右键菜单。

如果菜单没有该项，不需要反复配置。先用拖入入口或应用中的事项列表。

## 没有日历权限可以用吗？

可以先用示例，或记录临时事项。拖入路线接收的是你主动提供的一条日程，不要求先读取整个日历；其兼容性仍以实际接收结果为准。

只有点击 **“连接苹果日历”**、希望在 NowDo 中显示日程列表时，才需要系统日历访问权限。Apple 的这项权限显示为完整访问；当前应用只读取，不创建、修改或删除日程。

## 为什么有些事项不显示？

先确认选的是正确日期，再在 **“设置”** 中检查该日历有没有被隐藏，最后点事项列表旁的刷新按钮。日历列表需要授权，并且相应账户已在系统日历中同步。

苹果日历中出现的 **提醒事项** 不等于日历事件，目前还没接入。也可能是具体账户同步或权限状态的问题；不要因此认为原日程被删除，NowDo 不删除原日历内容。

## 可以同时给多个事项计时吗？

可以保存多件事，每件分别累计；一次只有一个计时器运行。开始另一件时，上一件自动暂停，避免同一段时间被重复统计。

## 点小点、拖小点、右键小点分别做什么？

| 操作 | 结果 |
| --- | --- |
| 点紫点 | 当前事项暂停或继续；还没有事项时展开窗口 |
| 拖动紫点 | 改变小点在桌面上的位置 |
| 点右侧箭头或右键紫点 | 展开 NowDo 窗口 |
| 把日程拖到紫点 | 尝试接收该事项并开始计时；以成功提示为准 |

## 暂停、退出、休眠以后会怎么样？

暂停保留已经累计的时间，再点继续会新增一段记录。正常退出和系统休眠会暂停，回来后由你继续。

意外退出时，恢复到最后保存点；正常心跳约 15 秒。磁盘满、文件损坏等异常可能影响保存，界面会提示。不要把这一恢复机制理解为断电时绝不丢失。

## 忘记暂停了，数字偏大怎么办？

先暂停，然后在 **“复盘 → 每一段记录 → 修正 / 备注”** 把结束时间改早并保存。当前只能缩短已经结束的记录。

应用不会自动看你打开了什么软件，也不会判断你是否离开电脑。它记录你手动开始和暂停之间的经过时间，不给你打效率分数。

## 同一件事为什么可能有两条记录？

日历事项改期、移动到其他日历或重新同步后，系统标识可能改变。未关联的拖入快照与后来读取到的日历事件，也可能成为独立事项。

应用只有在事件标识、时间等信息唯一吻合时才关联，不按同名猜测。旧记录会保留，但目前没有自动合并或手动合并界面。重复日程如果没提供具体实例日期，只保留独立计时，不虚构原计划。

## 免费吗？需要 AI 会员或者 API Key 吗？

当前源码按 [MIT 许可](../LICENSE)免费开放。没有账号、订阅、AI 调用或按次收费，不需要 AI 会员或 API Key。

从源码构建需要 Mac 开发环境。公开安装包的签名、公证、兼容性测试与后续维护仍有开发投入；这些不应被说成“完全没有维护成本”。

## GitHub 下载了源码，为什么打不开？

源码压缩包不是已经安装好的 Mac 应用。已有 [v2.0.0 Apple Silicon 预览安装包](https://github.com/wangyiwen11/nowdo-web/releases/tag/v2.0.0)：下载 `NowDo-v2.0.0-macOS-arm64.zip`，解压后把 `.app` 放进 Applications，再打开。不想使用预编译包时，也可按 [构建说明](../README.md#从源码运行)自行生成。

GitHub 自动测试和构建通过，公开包的下载、SHA256 和临时签名已检查。但包还没有 Apple Developer ID 签名或公证，跨机器图形界面安装也未完整验收。系统可能拦截首次打开；确认来源可信后可使用系统设置提供的打开选项。不要为了运行来路不明的文件关闭系统整体安全保护。

## 我的数据会被公开吗？

开源公开的是程序源码，不是你的数据。计时记录写在本机：

`~/Library/Application Support/NowDoDot/time-records.json`

当前应用不上传计时记录，不连接 AI 服务，不监视通用剪贴板。日程拖入只处理主动传给应用的数据；系统日历本身是否同步到 iCloud 或其他账户，由你的系统设置决定。

你主动导出的 CSV、JSON 或截图可能包含事项名称和备注，分享前自行检查。

## 怎样备份、恢复或删除记录？

备份：**设置 → 备份全部记录**，将 JSON 保存在你自己选择的位置。导出当天 CSV 用于阅读与分析，不能代替完整备份。

恢复目前需要手动操作：正常退出 NowDo，先另存现有数据文件，把 JSON 备份复制到上面的目录并命名为 `time-records.json`，重新打开。尚无应用内恢复按钮；不要在应用正在运行时替换文件。

删除应用不会自动清理这份记录。若决定彻底删除，先退出，在 **“打开数据文件夹”** 指向的位置移走记录文件；你导出到其他位置的备份也要分别处理。删除前应确认不再需要，公开源码与此无关。

## 网页版、iPhone 和其他 Mac 能同步吗？

目前不能。此版只做 Mac 本地计时，与原有网页版记录独立；尚未做迁移、iPhone 应用或跨设备同步。

## 它能改善 ADHD 吗？

目标是减少重复找任务、让暂停和继续更容易看见。对容易被打断或忘记计时的人是否有帮助，需要真实使用验证。它没有经过临床效果验证，也不作改善症状的承诺。
