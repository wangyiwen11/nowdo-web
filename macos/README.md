# NowDo · 计时点

**日历里排好的事，实际花了多久？用一个紫色小点记下来。**

NowDo 是一个 Mac 悬浮秒表。开始一件事，点小点暂停或继续，结束后看实际用时，给下次安排留一个参考。

**v2.0 · 开源预览版。** 免费，采用 [MIT 许可](LICENSE)，无需账号、订阅或 AI API。当前提供源码与本机测试构建；公开安装包尚未完成发行与公证验证。苹果日历拖入修复仍需真实操作回归，见[验证状态](#验证状态)。

## 它帮你少做什么

你已经在日历里安排了事情，却还要在另一个工具里重新找一次；被打断后，又不记得之前花了多久。NowDo 把这两步接起来：

| 现在的困难 | NowDo 的处理 |
| --- | --- |
| 日历里已经选好了，不想重新输入 | 将一条日程拖到紫点，接收后直接开始；拖入兼容性正在验证 |
| 被打断后忘了停在哪 | 点一下暂停，再点一下继续累计；可以留一句进度 |
| 换一件事时忘了停上一件 | 新事项开始时，上一件自动暂停 |
| 下次安排只能凭感觉 | 在“复盘”看实际用时、分段记录和原计划 |

例如：计划读文章 30 分钟，实际分两次记录了 42 分钟。复盘会保留这两段时间，你可以写下“查资料多用了 12 分钟”，下次再调整计划。**这是使用示例，不是实际用户效果数据。**

## 日常只用三个动作

1. **开始一件事。** 把一条日历事项拖到紫点或窗口顶部，看到“正在记录”和时间开始增加，才算接收成功。也可在已连接的日历列表中点击事项。
2. **点紫点暂停或继续。** 换事项会自动暂停上一件；小点可以挪位置，旁边的小箭头用于展开窗口。
3. **打开“复盘”。** 看当天实际花了多久；忘记暂停时，可把一段记录的结束时间改早，并补一句备注。

第一次可打开 **“设置 → 看一遍 22 秒使用演示”**，或者点 **“先用示例试试”**。示例不写入正式记录。已有本机构建的开发者也可运行自动演示，见文末。

**拖入没反应时不用反复尝试。** v2.0 已补上苹果日历的异步日程文件交付，新增了接收中状态、超时和错误提示，真实拖拽仍待确认。先用“加一件临时事项”开始记录，或连接日历后点选事项；[排查说明](docs/FAQ.md#日程拖到紫点没有反应怎么办)会说明成功标志与回退方式。

## 适合怎样使用

适合已经用苹果日历安排事情、想记录实际投入、容易在切换任务时忘记计时的人。Mac 上有时段和全天的日历事项都纳入设计范围；全天事项只记实际用时，不把一天算成计划时长。

如果需要自动识别所有电脑活动、团队工时审批、计费或多设备同步，当前版本不足以承担这些工作。NowDo 一次只计一件事，也不会自动判断你是否正在工作。

本项目保留原有网页版；Mac 原生版的记录与网页版独立，暂不迁移或同步。公开源码不会公开你的日历与用时记录。

## 记录放在哪里

计时记录保存在这台 Mac。应用保存对应事项的名称、日历名称、计划快照、实际时间段和你填写的备注；不修改原日程，不上传计时记录，不接入 AI。系统自身的 iCloud 或其他日历同步仍受系统账号设置控制。

- **设置 → 备份全部记录**：保存完整 JSON 备份。
- **复盘 → 导出当天**：导出所选日期的 CSV。
- **设置 → 打开数据文件夹**：查看本机记录位置。

休眠或正常退出时暂停。异常中断会恢复到最后保存点，正常心跳间隔约 15 秒；磁盘写入失败会显示错误，不能保证异常情况下零丢失。备份、恢复与权限说明见 [FAQ](docs/FAQ.md)。

## 从源码运行

需要 Mac、Swift 开发工具与 macOS SDK。当前构建在 Apple Silicon 上验证；不会要求购买服务或填写 API Key。没有开发工具的普通用户，目前仍需要他人协助构建，不能把源码下载当作安装完成。

在原生版目录中运行；如果它位于仓库的 `macos/` 下，先进入该目录：

```sh
./scripts/build-app.sh
./scripts/test-core.sh
./scripts/test-import.sh
./scripts/test-drop.sh
open "dist/NowDo 计时点.app"
```

只看自动演示：

```sh
"dist/NowDo 计时点.app/Contents/MacOS/NowDoDot" --guided-demo
```

演示用独立内存数据，不读取日历、不写入正式计时记录。正常使用请通过 Finder 打开 `.app`，以便系统把日历授权授予应用本身。

合成数据的应用检查与界面预览：

```sh
"dist/NowDo 计时点.app/Contents/MacOS/NowDoDot" --render-preview "$PWD/docs/previews"
```

该模式不读取真实日历。若开发环境已有截图权限，只捕获自身示例窗口；正常使用不截图，也不需要录屏或辅助功能权限。构建脚本使用本机签名，它不等于 Apple Developer ID 公证。

代码使用 Swift、AppKit、SwiftUI 和 EventKit，没有第三方 Swift 包依赖。计时核心在 `Sources/NowDoCore/`，Mac 窗口、日历入口和演示在 `Sources/NowDoDot/`。
